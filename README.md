### 🧭 How I work

```text
1. pick a real threat          → something attackers are doing right now
2. run the experiment safely   → my own accounts, sandboxes, public data only
3. capture everything          → screenshots, timelines, raw evidence
4. map it                      → MITRE ATT&CK techniques
5. defend it                   → how to detect it and how to stop it
```
